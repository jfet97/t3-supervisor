A workflow status inside a reached return region can no longer be moved backward by an ordinary apply: the Supervisor settles the assessing member, the service requests the return, and applying it is the only way a new attempt starts and a jump is spent. Off the selected path a misrecorded status is corrected with an explicit repair flag that starts no attempt. Applied receipts state the document's own status.
